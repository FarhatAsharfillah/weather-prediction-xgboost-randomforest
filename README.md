#  Daily Rainfall Prediction: XGBoost vs Random Forest


##  Project Overview
This repository presents a comparative machine learning study evaluating the performance of **XGBoost (Boosting)** and **Random Forest (Bagging)** in predicting daily rainfall fluctuations. A major focus of this project is addressing severe class imbalance in public historical weather datasets to build a robust early warning prediction model.

---

##  The Class Imbalance Problem & SMOTE Solution
Historical weather data is naturally skewed, which often causes machine learning models to become biased toward predicting the majority class (sunny days). 

* **Initial Distribution:** The raw dataset was heavily imbalanced, consisting of 43,993 "Sunny" instances (~78%) and only 12,427 "Extreme Rain" instances (~22%).
* **SMOTE Injection:** To resolve this, the Synthetic Minority Over-sampling Technique (SMOTE) was applied to synthesize minority class data.
* **Balanced Output:** The training data achieved a perfect 50:50 ratio, containing 35,194 instances for both sunny and extreme rain classes.

---

##  Methodology & Data Pipeline

* **Predictor Features:** The models were trained using key meteorological variables: Temperature, Humidity, Wind Speed, and Atmospheric Pressure.
* **Strict Data Splitting (80/20):** To prevent data leakage, the dataset was strictly split[cite: 14]. SMOTE was **only** applied to the 80% Training Set. 
* **Real-World Simulation:** The remaining 20% Testing Set was kept in its original, imbalanced state to objectively simulate real-world weather forecasting scenarios.

---

##  Model Performance & Evaluation
Both models were evaluated comprehensively using accuracy, F1-Score (crucial for imbalanced data), RMSE, and MAE.

| Evaluation Metric | Random Forest (Bagging) | XGBoost (Boosting) |
| :--- | :--- | :--- |
| **Accuracy** | 81.73% | **82.10%** |
| **F1-Score** | 0.5868 | **0.5998** |
| **RMSE** | 0.4275 | **0.4231** |
| **MAE** | 0.1827 | **0.1790** |


### Performance Analysis:
* **Superior Sensitivity:** XGBoost outperformed Random Forest across all metrics. The higher F1-Score (0.5998) indicates that XGBoost is significantly more sensitive and robust in recognizing extreme weather anomalies generated by SMOTE.
* **Minimized Error Rates:** XGBoost recorded lower deviation values (RMSE: 0.4231, MAE: 0.1790), proving its predictions are closer to actual ground truth conditions.

---

##  Conclusion
The **XGBoost** algorithm demonstrates superior computational resilience, higher accuracy, and lower error margins compared to Random Forest for daily rainfall prediction. 

The boosting architecture—which iteratively evaluates and reduces errors from previous decision trees—proved highly effective at deciphering extreme weather patterns. Combined with SMOTE preprocessing, XGBoost serves as an optimized baseline algorithm for developing future extreme weather early warning systems.
